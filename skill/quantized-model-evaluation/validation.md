## GREEN：桌面应用检查

**测试输入**：E09 两种 golden、E04／E05 两类工作点，以及最终 343 张 PL 批处理。

**最终收束材料时参与人机协同的执行 Agent 应用结果**：

- 将 PL 批处理绑定到定点参考和冻结工作点，接受 343 张端到端差异为 0 的结论，但不用于排名其他量化候选；

- 区分 binary F1／macro-F1，不把单病种缺失类指标解释为六分类性能。

**结论**：`PASS_WITH_NOTES`。Skill 能维持参考、工作点、指标和 split 的身份链。该检查由最终收束材料时参与人机协同的执行 Agent 基于冻结材料完成，不是独立 Agent 压力测试或新增模型评估。
