# 异构系统性能测量与受控对照：验证记录

## RED：历史失败基线

**场景 A**：SYS-Round01 初测两轮使用不同实拍输入，baseline 有 I/O 尖峰。直接以两组均值计算加速比会把输入工作量和 I/O 差异归因给代码优化。

**场景 B**：固定输入复测的普通完整归档中位数由 1,564 ms 降至 530 ms，但 P95 由 1,753 ms 升至 2,697 ms。只报中位数会隐藏尾部退化。

**场景 C**：硬件事务约 48.86 ms 与标准化输入到 logits 约 69.50 ms 边界不同；任选一个与历史 CPU 数字拼接都会形成虚假加速比。

来源：`HISTORICAL_ARTIFACT`，SYS-Round01 与 PL 批处理。

## GREEN：桌面应用检查

**测试输入**：SYS-Round01 初测、固定输入 ABBA 复测，以及 PL 批处理计时分项。

**最终收束材料时参与人机协同的执行 Agent 应用结果**：

- 将初测标为非受控趋势证据，将固定输入、预热排除和 ABBA 复测作为正式对照；
- 同时列出均值、中位数和 P95，保留普通模式尾部变差；
- 把约 48.86 ms 和约 69.50 ms 分别绑定到硬件事务与标准化输入到 logits，不生成跨边界加速比；
- 将离板保存归档结果限定为归档路径，未写成摄像头视频吞吐、首屏延迟或连续实时保证；
- 将尖峰差值保留为未分解余量，未归因给未单独测量的函数。

**结论**：`PASS_WITH_NOTES`。Skill 能阻止非受控输入、边界混用和尾部遗漏。该检查由最终收束材料时参与人机协同的执行 Agent 基于冻结材料完成，不是独立 Agent 压力测试或新增性能测量。
