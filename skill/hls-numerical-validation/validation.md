# HLS 数值等价与分层验证：验证记录

## RED：历史失败基线

**场景 A**：一个定点候选只有六样本原生误差，缺少完整 validation 证据。若只凭该误差值就淘汰候选，会把小样本运行检查误当成模型选型依据。

**场景 B**：新位宽候选被既有 GAP 类型断言拦截。若直接删除断言，可能同时失去对几何、舍入、累加和算术条件的保护。

**后续真实反馈**：Round27 从冻结图像、预处理和顺序重建 6 个 golden＋342 个 validation 输入，先逐层重现原生完整码，再比较三个候选的完整指标。类型问题通过新增明确的 8/4→8/3 配对解决，而不是移除保护。后续 Round39 又验证多帧、边界帧、ROM 重排和 RTL 周期；最终 343 张 PL 批处理与定点参考的 logits、概率和决策差异均为 0。

**由此形成的测试要求**：

1. golden smoke、完整指标、逐层数值、RTL、物理实现和板端必须分层；
2. 输入、预处理、标签、参考和模型身份必须可追踪；
3. 只有证明乘积对齐、舍入／饱和与部分和条件后，才可使用快速整数重放；
4. 小样本一致和全量一致、数值误差更小和分类指标更好不得互相替代。

来源：`HISTORICAL_ARTIFACT`，Round27、Round39 和 PL 批处理。

## GREEN：桌面应用检查

**测试输入**：Round39 的 4 帧、9 边界帧、ROM 与 RTL 周期证据，以及最终 343 张 PL 批处理汇总。

**最终收束材料时参与人机协同的执行 Agent 应用结果**：

- 将 Round39 归为 C／RTL 与局部物理实现证据，没有把 4 帧或 9 边界帧外推为 342 张完整 RTL 验证；
- 将最终 343 张 PL 批处理归为当前最高层端到端数值证据：logits 与概率 max／mean 误差、argmax／阈值决策分歧、raw mismatch 均为 0；
- 核对温度 `0.8835169076919556`、阈值 `0.7097623636691894` 和 `quality_gate_applied=false`，没有把数值一致性写成质量门通过；
- 保留 `test_scope=Source development-evaluation split, not untouched blind test`，没有称为未见盲测；
- 核对 DMA 复位、核复位、HP1 恢复和缓冲释放均完成，同时拒绝由该批次推断长期稳定性。

**结论**：`PASS_WITH_NOTES`。Skill 能区分 smoke、完整候选评估、RTL、物理实现与板端证据，且没有越过测试范围。该检查由最终收束材料时参与人机协同的执行 Agent 基于冻结材料完成，不是独立 Agent 压力测试或新增板测。
